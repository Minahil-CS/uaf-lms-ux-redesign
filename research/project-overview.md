# Project Overview
**Case study:** UAF LMS (https://lms.uaf.edu.pk/)
**Tools:** Figma (wireframing/prototyping), GitHub (documentation)

## Deliverables
1. Usability evaluation of the existing LMS
2. Evaluation report with evidence
3. Redesigned wireframes (Figma)
4. GitHub repository with all work

## HCI Design Life Cycle
1. Understand users and their needs
2. Specify requirements
3. Design solutions (sketches, wireframes)
4. Build prototypes (Figma)
5. Evaluate the design
